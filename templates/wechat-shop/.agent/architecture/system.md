# WeChat Shop System Baseline

- Mini Program: native WeChat Mini Program
- Admin: Vue 3 + Vite
- Backend: Spring Boot 2.7.18 / Java 17
- Database: MySQL + Flyway migrations
- Cache: Redis
- Payment: WeChat Pay API v3 official Java SDK 0.2.17
- Delivery rule: feature branch -> CI -> review -> PR -> merge -> memory
