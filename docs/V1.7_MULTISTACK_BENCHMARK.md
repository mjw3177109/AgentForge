# AgentForge V1.7 Multi-Stack Benchmark

This benchmark validates the autonomous pipeline against a realistic WeChat commerce stack in GitHub Actions.

The CI job starts MySQL 8 and Redis 7 service containers, installs Java 17, Maven, Node 20, MySQL client and Redis tools, and then runs one end-to-end request:

`给商城增加优惠券功能`

Expected autonomous flow:

1. Requirement -> REQ-970001
2. Architecture -> ADR-970001
3. Task DAG -> Database -> Backend -> MiniApp + Admin
4. Database Agent writes and executes a MySQL migration
5. Backend Agent writes Spring Boot 2.7 code, fails Maven test once, receives real failure feedback, repairs, then passes
6. Redis connectivity gate passes
7. MiniApp Agent passes Node test against the architecture-defined API
8. Admin Agent produces Vue3 code and Vite build passes
9. Reviewer approves only after all orchestrator-owned verification gates pass
10. Git creates five feature commits, pushes to a bare remote, and the GitHub-compatible publisher sends a pull-request request

The OpenAI-compatible model endpoint and PR endpoint are local HTTP test doubles inside CI. The MySQL, Redis, Maven, Node and Vue/Vite executions are real.

Auto-merge remains forbidden.
