# AgentForge V1.4 Live Agent Runtime

V1.4 replaces planning mocks with an OpenAI-compatible HTTP model boundary.

## Safety boundary

The model can only return structured REQ / ADR / TASK data. It does **not** receive direct Git, shell or filesystem write authority.

The resulting plan must pass:

1. Pydantic schema validation
2. requirement -> ADR traceability
3. task -> REQ/ADR traceability
4. dependency existence checks
5. explicit `change_required=false` scope guard
6. later Evidence / Policy / Verification gates

## Configure

```bash
export AGENTFORGE_LLM_BASE_URL=https://your-provider.example/v1
export AGENTFORGE_LLM_API_KEY=...
export AGENTFORGE_LLM_MODEL=your-model
agentforge plan "增加商品收藏功能"
```

For compatible self-hosted services, `AGENTFORGE_LLM_BASE_URL` may also point directly to `/chat/completions`.

## CI

Tests run a real local HTTP server implementing the OpenAI-compatible response shape. This verifies the network serialization boundary without requiring external secrets.
